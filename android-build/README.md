# 联播夜读 · 安卓独立版 2.2.4（原片原声 + 后台播放）

手机 / 平板可直接安装的原生 Android 应用。**安装后不再需要电脑、本地服务或局域网**；新闻抓取、摘要生成和原片播放全部在手机本地完成，只需要联网获取央视网与 B 站公开内容。

**完全没有 TTS 合成语音。** 新闻播报使用央视《新闻联播》原片视频和原声；UP 联动使用 B 站原视频和原声。

- 安装包：[`output/联播夜读-2.2.4.apk`](output/联播夜读-2.2.4.apk)（约 68 MB，含离线语音模型）

## 安装

1. 把 `output/联播夜读-2.2.4.apk` 发送到 Android 手机或平板（微信文件传输、数据线、网盘均可）。
2. 点击 APK 安装；如果系统提示，请允许「安装未知来源应用」。
3. 桌面会出现「联播夜读」图标，点击即可使用。

> 当前包名为 `com.lianbo.mobile`，后续更新使用同一签名证书即可覆盖安装。

## 原片、原声与切片

### 新闻联播

- 每一条新闻都有独立的央视原片片段，应用内直接播放 **视频 + 原声**。
- 使用 CCTV 的 HLS 原片；页面中的「播放原片」「全屏原片」「原片清单」都指向原片，不使用任何合成朗读。
- 「原片清单」的播放进度、连续播放、上下条均针对原视频。
- **文字稿与原片同屏（1.1.3）**：在「今日报道」点「文字稿」后，原片用原生播放器悬浮；**竖屏顶置、横屏右置**。横屏右侧包含视频、进度、播放/暂停、上下条、静音、连续播放和原片清单，体验与电脑端一致；文字稿中当前播放到的句子自动高亮并滚动到可见位置。
- **字幕（1.1.3）**：只要原片正在播放，悬浮、右置、全屏都显示视频内字幕，并与文字稿当前句高亮同步；默认开启，可点「字幕 开/关」切换。
- **全屏原片**：点视频右下角「⛶ 全屏」、面板内「全屏」、条目「全屏原片」或悬浮播放器的「全屏」进入原生全屏；默认横屏，字幕默认开启并位于视频画面内中下方，可点「字幕 开/关」切换。字幕由该条新闻对应的央视原稿自动切分并对齐到原片时间，不是 TTS。
- **清晰度**：移动端与桌面端都优先选择 CCTV HLS 1200 档（1280×720）；桌面端 hls.js 也自动选最高码率档，避免全屏放大后过糊。
- 原生播放器使用 Android `VideoView` 播放 HLS，避免 WebView 在悬浮/全屏时可能出现的黑屏问题。

### B 站 UP 联动

- 文本、UP 名称和引语都链接到对应 B 站原视频。
- 提供 **B 站原视频内嵌播放器**：包含原视频画面和原声，可全屏、拖动。
- 小谢、原点公社的「原声片段」按钮会按当天匹配的话题打开 B 站播放器。
- B 站没有向普通用户开放这些视频的字幕/章节时间码，因此**话题起点是按标题、简介中的话题顺序估算的**，不是精确字幕轴；打开后可在播放器中拖动到准确位置。应用内已明确标注「按话题顺序估算」。

## 使用

- **首次启动**：加载内置本地新闻引擎（Pyodide + Python）并抓取最新一期，通常需要 20–60 秒。
- **后续打开**：使用本地缓存，秒开；点右上角「↻」更新最新一期。
- **手机 / 平板**：自动切换布局；平板上的视频在右侧原片面板，手机在重点之后。
- **无需电脑**：安装完成后，电脑关机也不影响手机/平板使用；仅需网络。

## 限制

- 需要联网：新闻、B 站和视频都来自公开网络。
- **不是后台自动更新**：打开应用后点右上角刷新获取最新一期；后台播放指已经打开的原片原声。
- **B 站话题切片为估算**：没有公开字幕时无法精确到秒；但视频、原声和文本链接都是真的原视频。
- 视频依赖央视/B 站 CDN：若个别网络无法播放，可点击「央视页」或「B站打开」外链。
- 个人签名 APK，不在应用商店；安装需允许未知来源。

## 构建

无需 Android Studio/Gradle：

```powershell
cd android-build
python build_apk.py
```

工具链已放在 `tooling/`：jdk4py JRE、ECJ、Android API jar、AAPT2、R8、apksig。

源码结构：

```
android-build/
├─ app/src/com/lianbo/mobile/MainActivity.java  # WebView + 本地资源拦截 + HTTP 桥
├─ app/src/AndroidManifest.xml
├─ app/assets/www/index.html / app.css / app.js # 手机/平板 UI、原片播放、B站弹层
├─ app/assets/www/pyodide/                      # 内置 Pyodide 运行时
├─ app/assets/www/py/                           # CCTV/B站/摘要 Python 代码
├─ app/assets/www/vendor.zip                    # jieba、bs4 等纯 Python 依赖
├─ build_apk.py
└─ output/联播夜读-2.2.4.apk
```

技术路径：WebView 通过 `shouldInterceptRequest` 从 APK assets 提供 `https://app.local/` 站点；Pyodide 在 WebView 内运行原 Python 管线；Python 通过 `AndroidBridge.httpRequest` 直接访问央视网/B 站；视频使用 WebView 原生 HLS；进入后台时由 `BackgroundAudioService` 前台服务接管音频并同步通知栏字幕，返回后恢复到原生播放器；全程不生成 TTS。
